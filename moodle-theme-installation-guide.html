🚀 Installation Methods

Method 1: Docker (Recommended for Development)

Quick Copy to Docker Container

  1. Open terminal in the directory containing moodle-theme-scl
  2. Run the copy command:
    docker cp moodle-theme-scl scli-moodle-dev:/bitnami/moodle/theme/scl
  3. Verify installation:
    docker exec scli-moodle-dev ls -la /bitnami/moodle/theme/scl
  4. Clear Moodle caches:
    docker exec scli-moodle-dev bash -c "cd /bitnami/moodle && php admin/cli/purge_caches.php"

Method 2: Manual File Upload (Production)

Upload via Web Interface

  1. Package the theme:
    tar -czf scl-theme.tar.gz moodle-theme-scl/
  2. Login to Moodle as Administrator
  3. Navigate to: Site Administration → Plugins → Install plugins
  4. Choose plugin type: Theme (from dropdown)
  5. Upload scl-theme.tar.gz file
  6. Click "Install plugin"

Method 3: SSH/SFTP Upload (Traditional)

Upload via SSH/SFTP to Linux Server

  1. Connect via SFTP:
    sftp user@your-server.com
  2. Navigate to Moodle theme directory:
    cd /path/to/moodle/theme
  3. Upload the theme folder:
    put -r moodle-theme-scl scl
  4. Set proper permissions (via SSH):
    chmod -R 755 /path/to/moodle/theme/scl

🎯 Activation in Moodle

Step 1: Login to Moodle

  1. Open Moodle in your browser:
    http://localhost:9090 (development)
    http://your-domain.com (production)
  2. Login with Administrator account:
    • Default username: admin
    • Password: Your configured password

Step 2: Access Theme Selector

  1. Go to: Site Administration (top-left menu)
  2. Click on Appearance
  3. Click on Themes
  4. Click on Theme Selector
  5. Or direct URL: http://your-moodle/admin/settings.php?section=themeselector

Step 3: Select SCL Theme

  1. Under "Available themes", find "SCL Institute"
  2. Click on the theme card
  3. Click the "Use theme" button
  4. Confirm by clicking "Save changes"

Step 4: Verify Installation

  1. Logout from the admin panel
  2. Clear your browser cache (Ctrl+Shift+R or Cmd+Shift+R)
  3. Refresh the page or navigate to login page
  4. You should see:
    • Purple gradient navigation bar
    • Purple buttons and links
    • Professional styling throughout
✅ Success! If you see the purple SCL color scheme, the theme is installed correctly.

🔧 Troubleshooting

Problem: Theme Not Showing in Theme Selector

Solution:

  1. Verify files are in correct location:
    ls -la {MOODLE_ROOT}/theme/scl/
  2. Check file permissions:
    chmod -R 755 {MOODLE_ROOT}/theme/scl/
  3. Clear Moodle cache:
    php admin/cli/purge_caches.php
  4. Restart web server and clear browser cache

Problem: Styling Not Applied

Solution:

  1. Hard refresh browser:
    • Windows: Ctrl + Shift + R
    • Mac: Cmd + Shift + R
  2. Try in Incognito/Private window (disables extensions)
  3. Clear Moodle cache via Site Administration
  4. Verify CSS file exists:
    test -f {MOODLE_ROOT}/theme/scl/style/scl.css && echo "File exists"

Problem: 404 - Theme Not Found

Solution (Docker):

  1. Check files in container:
    docker exec scli-moodle-dev ls /bitnami/moodle/theme/scl
  2. Restart container:
    docker restart scli-moodle-dev
  3. View logs:
    docker logs scli-moodle-dev | tail -50

🎨 Customization

After Installation

Once the theme is activated, you can customize it via:

Site Administration → Appearance → Themes → SCL Theme Settings

Customizable Options

  • Brand Color: Change primary purple to your color
  • Logo: Upload your institution logo
  • Background Image: Set page background
  • Font Family: Choose between Sans Serif, Serif, Monospace
  • Font Size: Small (12px), Normal (14px), Large (16px)

Advanced CSS Customization

For advanced users, edit CSS variables in style/scl.css:

:root { --scl-primary: #7c3aed; /* Change primary color */ --scl-secondary: #0ea5e9; /* Change secondary color */ --scl-accent: #10b981; /* Change accent color */ }
