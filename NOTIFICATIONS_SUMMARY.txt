📋 WHAT WAS BUILT

A complete in-app notification system that stores and displays all student
notifications including:

✅ Welcome notifications (with login credentials)
✅ Conditional offer notifications (with conditions)
✅ Rejection notifications
✅ Administrative updates
✅ Real-time updates in navbar
✅ Full notification center page
✅ Filter by type and read status
✅ Mark as read/unread functionality

🚀 HOW IT WORKS

Step 1: Admin Approves Student
┌──────────────────────────────────────────────────────────────────┐
│ Admin clicks "Approve" on pending application                   │
└──────────────────────────────────────────────────────────────────┘

Step 2: Backend Creates Account
┌──────────────────────────────────────────────────────────────────┐
│ Backend creates user in SCL database with temporary password    │
└──────────────────────────────────────────────────────────────────┘

Step 3: Backend Stores Notification
┌──────────────────────────────────────────────────────────────────┐
│ await storeNotification(                                          │
│     student@email.com,                                           │
│     'welcome',                                                   │
│     'Welcome to SCL Institute',                                  │
│     'Full notification body...',                                 │
│     {                                                            │
│         applicant_name: 'John Doe',                              │
│         course: 'Computer Science',                              │
│         credentials: {                                           │
│             email: 'student@email.com',                          │
│             password: 'abc123def456'                             │
│         },                                                       │
│         moodle_enrollment: true,                                 │
│         portal_url: 'http://localhost:3000',                     │
│         moodle_url: 'http://localhost:9090'                      │
│     }                                                            │
│ )                                                                │
└──────────────────────────────────────────────────────────────────┘

Step 4: Student Sees Notification
┌──────────────────────────────────────────────────────────────────┐
│ 1. Navbar shows:                                                 │
│    ├─ Red badge with "1" (unread count)                          │
│    └─ Bell icon highlighted                                      │
│                                                                  │
│ 2. Click bell to see dropdown:                                   │
│    ├─ Recent notifications listed                                │
│    ├─ Click to mark as read                                      │
│    └─ "View All" link to full page                               │
│                                                                  │
│ 3. Click on notification or "View All":                          │
│    ├─ Full page opens                                            │
│    ├─ See complete notification content                          │
│    ├─ See all structured data:                                   │
│    │  ├─ Name                                                    │
│    │  ├─ Course                                                  │
│    │  ├─ Login credentials                                       │
│    │  ├─ Portal URL                                              │
│    │  └─ Moodle URL                                              │
│    └─ Can bookmark for reference                                 │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

Step 5: Student Uses Information
┌──────────────────────────────────────────────────────────────────┐
│ Student reads credentials from notification and:                │
│ 1. Login to portal: http://localhost:3000                        │
│ 2. Login to Moodle: http://localhost:9090                        │
│ 3. Start accessing course materials                              │
│                                                                  │
│ All without receiving external email!                            │
└──────────────────────────────────────────────────────────────────┘

🔗 REST API ENDPOINTS

BASE: /api/notifications

GET    /user/:email                 ← Get all notifications
GET    /user/:email?unread_only=true ← Get unread only
GET    /unread-count/:email         ← Get unread count
PUT    /:id/read                    ← Mark as read
PUT    /user/:email/read-all        ← Mark all as read
GET    /type/:type                  ← Get by type
GET    /type/:type?email=...        ← Get type for user
GET    /:id                         ← Get specific notification
DELETE /cleanup/old                 ← Delete old notifications

Example:
GET /api/notifications/user/student@scl.edu
└─ Returns: All notifications for that student
