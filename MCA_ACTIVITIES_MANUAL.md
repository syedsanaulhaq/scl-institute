# MCA Course Activities - Manual Implementation Guide

## Section 1: Programming Fundamentals
### Activities to Create Manually:

1. **Assignment: Variables and Data Types Exercise**
   - Type: Assignment
   - Points: 50
   - Due Date: Week 2
   - Description: Create a program demonstrating proper use of variables, data types, and type casting in your chosen language (Java/Python)
   - Submission Format: Source code (.java or .py file)

2. **Assignment: Control Flow Implementation**
   - Type: Assignment
   - Points: 100
   - Due Date: Week 3
   - Description: Build a menu-driven calculator using loops and conditional statements
   - Requirements: Handle user input, error handling, multiple operations

3. **Quiz: Programming Basics Assessment**
   - Type: Quiz
   - Points: 50
   - Questions: 15-20 multiple choice questions
   - Topics: Variables, data types, operators, control structures, functions

4. **Forum: Programming Problems Discussion**
   - Type: Forum
   - Description: "Share and discuss programming challenges you encounter. Ask for help and assist peers"

- **Subtotal: 300 points**

- Semester project checkpoint (mid-point submission): **150 points**

### Final Project (30%):
- Complete semester project + presentation: **150 points**

### Total: 600 points

## Manual Steps to Add Activities in Moodle:

1. **Login as Admin** → Navigate to course
2. **Turn Edit On** (top right)
3. **Click "Add an activity or resource"** in desired section
4. Choose activity type (Assignment, Quiz, Forum, etc.)
5. Fill in details:
   - Name
   - Description
   - Due date (if applicable)
   - Points/Grade
   - Submission type (if assignment)
   - Additional criteria
6. Save and return to course

---

## Tips for Creation:

✓ Use clear, descriptive titles
✓ Add detailed instructions in description
✓ Set realistic due dates (1-2 weeks spacing)
✓ Stagger major assignments to avoid overload
✓ Use grading rubrics for consistency
✓ Enable student discussions/forums for peer support
✓ Schedule quizzes at end of each section as validation
